# Calculadora - Practica 2

## Descripcion

Calculadora desarrollada en Python que permite realizar operaciones matematicas mediante un menu interactivo, validar entradas y consultar el historial de operaciones.

## Operaciones

| Operacion | Estado |
|---|---|
| Suma | Implementada |
| Resta | Implementada |
| Multiplicacion | Implementada |
| Division | Implementada |
| Potencia | Implementada |
| Modulo | Implementada |
| Raiz cuadrada | Implementada |
| Porcentaje | Implementada |
| Valor absoluto | Implementada |
| Factorial | Implementada |
| Promedio | Implementada |
| Redondeo | Implementada |

## Funcionalidades adicionales

- Validacion de entradas no numericas.
- Control de division y modulo entre cero.
- Menu interactivo.
- Repeticion de operaciones sin reiniciar.
- Historial de operaciones.
- Opcion para borrar el historial.

## Tecnologias

- Python 3
- Git
- GitHub
- Markdown

## Instalacion y ejecucion

1. Clonar el repositorio.
2. Abrir una terminal en la carpeta del proyecto.
3. Ejecutar:

```bash
python calculadora.py
```

## Archivos

- `calculadora.py`: menu e interaccion con el usuario.
- `operaciones.py`: funciones matematicas.
- `README.md`: documentacion.
